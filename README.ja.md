# SNSのアプローチ業務をAIエージェントに

**SNS運用・グロースチームのためのAIワークフォース。** クリエイターへの連絡、顧客との対話、投稿、フォローアップを、チームの管理のもとでマネージドクラウドフォン上で進めます。

## 💬 語られることの少ない日々の作業

SNSのアプローチ業務には、今もソフトウェアに任せにくい作業が多くあります。アプリ内の重要な操作に、適切な公開連携機能が用意されていないためです。

候補者のリストを開き、定型文に見えない最初のメッセージを考える。その後はコピー＆ペースト、3日後・7日後のフォローアップ、返信の確認、なかなか一致しない進捗欄の更新が続きます。

代理店では、こうした送信と記録をバーチャルアシスタントに任せることもあります。候補者が50人から200人に増えたり、1日500人への連絡を求められたりすると、表計算シートがボトルネックになります。

TikTok、Instagram、LinkedInでは、メッセージ連携やアクセス権にそれぞれ制限があります。予約投稿ツールやSNS管理ツールが投稿とレポートを担う一方、アプリ内での対話やフォローアップには手作業が残っています。

**CoreMateは、この業務を支えるための製品です。**

## ✨ CoreMateとは

CoreMateはSNSアプリのためのAIワークフォースです。AIエージェントが実際のモバイルアプリ内でタップ、入力、画面の確認、メッセージ送信、結果の記録を行います。クラウドフォンのホスティング、更新、保守は私たちが担当します。

普段の言葉で目標を伝えると、エージェントがチームで確認できる手順に整理し、設定された複数のクラウドフォンで並行してタスクを進めます。実行の経過はログで確認できます。

### 📱 アプリ内で作業

アプリ画面を操作し、メッセージ、フォローアップ、プラットフォーム固有の業務を進めます。利用できるタスクは、プラットフォーム、アカウント権限、対応ワークフローによって異なります。

### 🎯 SNSチームのための設計

コーディングは不要です。組み込みのプレイブックから始めることも、自分の言葉でタスクを説明することもできます。実行前に手順、内容、範囲をチームで確認します。

### 🤝 チームが主導権を維持

連絡内容や公開の判断はチームが行い、アカウントに適したペースを設定してログを確認します。対話や本人確認に人の対応が必要な場合は、チームが引き継ぎます。

## 🧭 エージェントに任せられる業務

| 活用場面 | 進められる業務 |
| --- | --- |
| 🤝 **クリエイターへのアプローチ** | 適切な候補の調査、個別の依頼文作成、サンプル送付の調整、コラボレーションのフォローアップ。TikTok Shopの販売者やDTCブランドを支援します。 |
| 💬 **顧客・B2Bへのアプローチ** | 候補リストと明確なビジネス上の目的に沿ったメッセージの準備、継続的な連絡、繰り返し作業の削減。 |
| 🌍 **複数アカウントの運用** | 管理権限のあるブランド・顧客アカウントを市場ごとに調整し、一つのワークスペースでタスクと記録を確認。 |
| 📝 **投稿とフォローアップ** | TikTok、Instagram、LinkedIn、Xの対応ワークフローでコンテンツを公開し、コメントや返信をフォロー。 |

## 🚀 導入までの4ステップ

### 1. 目標を決める

アプリ、アカウント、ワークフロー、必要なクラウドフォンの台数を選びます。実行前に範囲と成功基準を合意します。

### 2. クラウドフォンを準備する

私たちがワークスペースとクラウドフォンを準備します。端末内で自分のアカウントにログインし、選んだタスクの準備を整えます。

### 3. 実際のワークフローを検証する

まず一つのタスクを最初から最後まで実行します。ログと成果物を確認し、調整してから利用を広げます。

### 4. サポートを受けながら拡張する

業務量に合わせてアカウントと端末を追加できます。操作ガイド、アプリ更新に伴う保守、チームのサポートが利用できます。
