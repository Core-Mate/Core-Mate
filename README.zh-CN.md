# Core-Mate

## 面向社媒运营与增长团队的 AI 工作伙伴

Core-Mate 帮助团队开展社交媒体触达、持续跟进和内容发布，协同处理多个账号的日常工作。用自然语言描述目标，审核任务与内容，再让 AI 助手在托管云手机上执行。

发布什么、面向谁、何时执行，由你的团队把关。

## Core-Mate 能帮你做什么

### 达人与客户触达

围绕目标人群组织个性化沟通，开展达人合作、伙伴联络和客户触达。设定沟通内容与跟进节奏，让多个账号的联系工作有序推进。

### 内容发布与日常互动

准备待审核的内容，安排已批准的发布任务，处理评论与回复，将持续更新和日常互动纳入团队的工作安排。

### 多账号任务协作

将不同品牌、市场和账号的任务放在同一个工作空间中管理。通过多台云手机协同执行，在一处查看任务进度。

### 市场与内容调研

收集达人、竞品和相关内容的信息，为活动策划提供参考。团队可以查看调研结果，进一步确定选题与行动方向。

### 过程查看与结果复盘

跟踪任务状态，查看执行记录与产出，让负责账号和内容的成员及时了解进展，并根据结果调整后续工作。

## 从一个目标开始

1. **描述目标。** 说明要运营的账号、目标人群和预期结果，也可以从内置任务指南开始。
2. **审核安排。** 与团队确认任务步骤、内容与执行时间。
3. **执行任务。** 将工作安排到托管云手机，并查看各账号的任务进度。
4. **查看结果。** 检查产出与执行记录，调整下一轮工作。

例如，一次新品发布可以串联 TikTok 与 X 的内容安排、文案审核、定时发布，以及发布后的评论跟进。

## 社交平台与云手机

Core-Mate 面向 TikTok、Instagram、LinkedIn、X 等社交平台的运营场景。具体可用任务取决于平台、账号权限和工作空间配置。

使用托管云手机，团队可以直接开展工作，减少维护手机设备的日常投入。团队也可以连接自有手机，并根据业务规模沟通所需的设备与服务方案。
